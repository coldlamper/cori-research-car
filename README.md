# cori-research-car

A responsive, single-page comparison of hybrid and plug-in hybrid SUVs, focused on size, power, efficiency and ride quietness.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.

The site will appear at `https://coldlamper.github.io/cori-research-car/`.

## Contents

- `index.html` — complete static site with embedded styling and no build step.
